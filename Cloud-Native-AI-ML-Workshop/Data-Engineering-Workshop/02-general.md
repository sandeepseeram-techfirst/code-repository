## General Points

1. Websites generate a wealth of data, including user behavior, product views, and click patterns. 

2. Data Lake: Built on MinIO, the data lake serves as a repository for storing raw, semi-structured and unstructured data. Generally, companies collect page views, events from the website and store them on Data Lakes for further analysis and usage.

3. Most companies use a system that can handle both structured data (like user and purchase records from MySQL) and semi-structured data (like website interaction events) while maintaining data consistency and enabling efficient queries.
